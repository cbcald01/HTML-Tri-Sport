# Tri and Succeed Sports Website

**CIS 150 | HTML & CSS**

## Project Overview
Created a Coaches webpage for Tri and Succeed Sports, a fictional triathlon training organization, as part of a web development assignment. The page introduces the coaching team and highlights their backgrounds, qualifications, and training experience.

## Features
- Displays profiles and images for three coaches.
- Includes a navigation menu for sports classes and related resources.
- Uses CSS styles for page layout, typography, colors, and navigation.
- Includes a testimonial and business contact information.

## Skills Demonstrated
